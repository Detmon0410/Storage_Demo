Create `apps/backend/src/utils/rounding.ts` with exactly:
```typescript
/**
 * Rounds a number to a fixed number of decimals using standard round-half-up semantics
 * (e.g. 2.345 -> 2.35), matching Thai VAT invoice convention. Per-line rounding is applied
 * before summing totals (decision resolved 2026-09-14, see .planning/STATE.md).
 */
export function roundHalfUp(value: number, decimals = 2): number {
  const factor = 10 ** decimals;
  return Math.round((value + Number.EPSILON) * factor) / factor;
}
```
This is the only rounding utility in the codebase (confirmed via RESEARCH.md — no existing
`round`/`toFixed(2)` helper was found anywhere in `apps/backend/src`). It will be imported by
`creditDiscountGate.ts` in 03-02-PLAN.md to avoid floating-point false negatives right at the
credit-limit/discount-limit threshold boundary. Do not modify `salesOrder.model.ts`'s existing
`toItemRows`/`orderTotals` in this task — retrofitting the pre-existing order-total math is out of
this phase's scope; only the new guard function (03-02-PLAN.md) needs this utility.
